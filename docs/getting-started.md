# 3 分钟了解接入：从第一台工兵鸭开始

[进入矿鸭](https://kyaminer.com/) · [English](getting-started.en.md) · [返回首页](../README.md)

本教程约需 3 分钟阅读，实际接入时间取决于网络和设备状态。截图全部为演示数据，命令框只含不可执行的占位说明。

## 开始前

准备一台你拥有或获授权管理的 HiveOS 设备，能够打开终端并使用 root/sudo 权限。设备需要能通过 HTTPS 访问矿鸭，每台设备应有独立的 HiveOS 矿机编号。先测试一台，并保存现有配置备份。

界面名称：鸭子窝＝矿场，工兵鸭＝矿机，飞行鸭＝飞行表，鸭蛋＝钱包管理。

## 1. 注册或登录矿鸭

打开 [kyaminer.com](https://kyaminer.com/)，注册账号或登录已有账号。右上角可以切换中文或英文。5 台以内基础设备管理免费；AI 额度和鸭王进阶授权单独管理。

## 2. 创建鸭子窝

进入“鸭子窝”管理页面，点击创建，填写便于识别的名称并保存。位置和备注可选。

![创建鸭子窝：示例名称 DEMO NEST](../assets/setup-create-nest.png)

## 3. 生成命令，在目标设备执行

在目标鸭子窝点击“一键接入”，核对名称，点击“复制命令”。在目标 HiveOS 设备终端粘贴并执行，按终端提示等待结果。

![一键接入窗口，命令已替换为不可执行的演示占位说明](../assets/setup-enrollment.png)

**不要复制截图里的文字。真实命令必须由你自己的账号、目标鸭子窝生成。** 命令包含接入凭据，不要上传 GitHub 或发到公开群聊。

接入会备份连接配置、切换管理地址并等待心跳，保留原有挖矿配置。不要在验证接入的同时批量更换飞行鸭或超频参数。

命令有效期以窗口显示为准，目前为 24 小时。同一条命令可用于多台设备；重新生成会使旧命令失效，不影响已接入设备。需要时可点击“停用接入命令”。

## 4. 返回列表，确认工兵鸭上线

进入“工兵鸭”列表，选择对应鸭子窝，确认设备名称、在线状态、GPU 数量、算力、温度和风扇。页面会自动刷新。

<img src="../assets/mobile-workers-demo.png" alt="手机端工兵鸭列表：演示设备与演示数据" width="390">

确认第一台设备数据正常，再逐步接入其余设备。下发操作后请查看回执，保存配置不等于设备已经执行成功。

## 没有上线怎么办？

| 现象 | 先检查 |
| --- | --- |
| 命令无效或过期 | 回目标鸭子窝重新生成，并使用最新命令 |
| 权限不足 | 检查是否具备目标设备的 root/sudo 权限 |
| 网络或证书错误 | 检查设备时间、DNS、HTTPS 连通性；不要跳过证书验证 |
| 没出现在预期鸭子窝 | 确认命令来自正确账号和鸭子窝，查看终端执行结果 |
| 已上线但没有算力 | 先查看挖矿日志、飞行鸭配置和软件状态；在线不等于正在正常挖矿 |

需要帮助时，参考 [反馈说明](../SUPPORT.md)，先遮挡账号、地址、认证配置及接入命令。
