# 接入矿鸭

## 1. 登录并创建矿场

打开 https://kyaminer.com/，注册或登录账号，在矿场管理中创建矿场。

## 2. 获取接入命令

点击目标矿场的“一键接入”，复制系统为这个矿场生成的命令。命令包含接入认证信息，不要发到 GitHub、群聊或公开截图中。

## 3. 在矿机执行

在你拥有或获授权管理的 HiveOS 矿机终端中执行命令。建议从一台测试机开始，并保存现有配置的备份。

## 4. 核对运行状态

回到矿机列表，检查矿场归属、矿机名称、显卡数量、算力、温度及功耗。未上报或离线时，先检查网络及接入结果，不要反复批量下发操作。

## 5. 配置运维功能

按需要设置飞行表、超频、监控与智能温控，查看命令执行结果。接入、保存配置和配置实际生效是不同阶段，以对应页面提示和设备回执为准。

不要照抄其他设备的超频参数。固件、驱动、显卡和锄头版本可能影响兼容性。
